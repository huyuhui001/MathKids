Privacy Policy

隐私政策

Last updated: December 1, 2025 | 最后更新：2025年12月1日

📱 Application Overview | 应用概述

English: This privacy policy applies to the "MathKid Adventure" (数学小子) application (hereby referred to as "Application") for iOS mobile devices. We are committed to protecting your privacy and ensuring transparency about our data practices.

中文： 本隐私政策适用于iOS移动设备的"MathKid Adventure"（数学小子）应用程序（以下简称"应用"）。我们致力于保护您的隐私并确保数据实践的透明度。

✅ No Data Collection | 不收集数据

✅ No Personal Information | 无个人信息

✅ No Server Communication | 无服务器通信

✅ All Data Stays on Your Device | 所有数据保留在您的设备上

🔒 No Data Collection | 不收集数据

English: The Application does NOT collect, store, or transmit any personal information from users. All user data, including:

  • Game progress and scores
  • User preferences and settings
  • Achievement data
  • Language preferences

...remains exclusively on the user's device and is never sent to any server or third party.

中文： 本应用不收集、存储或传输用户的任何个人信息。所有用户数据，包括：

  • 游戏进度和分数
  • 用户偏好和设置
  • 成就数据
  • 语言偏好

...完全保留在用户的设备上，绝不会发送到任何服务器或第三方。

🔐 Local Data Storage | 本地数据存储

English: The Application uses iOS's built-in UserDefaults system to store user preferences and game progress locally on your device. This data:

  • Is stored only on your device
  • Is not synchronized with iCloud or any cloud service
  • Is not accessible to us or any third party
  • Can be deleted by uninstalling the app

中文： 本应用使用iOS内置的UserDefaults系统在您的设备上本地存储用户偏好和游戏进度。这些数据：

  • 仅存储在您的设备上
  • 不与iCloud或任何云服务同步
  • 我们或任何第三方无法访问
  • 可通过卸载应用程序删除

🚫 No Permissions Required | 无需权限

English: The Application does NOT request any device permissions, including but not limited to:

  • Location services
  • Camera access
  • Microphone access
  • Contacts access
  • Photo library access
  • Network connections (except for optional GitHub link viewing)

中文： 本应用不请求任何设备权限，包括但不限于：

  • 位置服务
  • 相机访问
  • 麦克风访问
  • 联系人访问
  • 照片库访问
  • 网络连接（除了可选的查看GitHub链接）

👶 Children's Privacy | 儿童隐私

English: This Application is designed for children and complies with children's privacy protection requirements. We do not knowingly collect personal information from children because we do not collect any personal information at all. The app is completely safe for children to use independently.

中文： 本应用专为儿童设计，符合儿童隐私保护要求。我们不会故意收集儿童的个人信息，因为我们根本不收集任何个人信息。该应用完全适合儿童独立使用。

🌐 Third-Party Services | 第三方服务

English: The Application does NOT use any third-party services, including:

  • No analytics services
  • No advertising networks
  • No crash reporting tools
  • No social media integration

The app functions entirely offline and does not communicate with any external servers.

中文： 本应用不使用任何第三方服务，包括：

  • 无分析服务
  • 无广告网络
  • 无崩溃报告工具
  • 无社交媒体集成

该应用完全离线运行，不与任何外部服务器通信。

🔄 Changes to This Policy | 政策变更

English: We may update this privacy policy occasionally to reflect changes in our practices or for other operational, legal, or regulatory reasons. Any updates will be posted on this page with a new "Last Updated" date. We encourage you to review this policy periodically.

中文： 我们可能会偶尔更新本隐私政策，以反映我们实践的变化或出于其他运营、法律或监管原因。任何更新都将在此页面上发布，并更新"最后更新"日期。我们鼓励您定期查看本政策。

  • GitHub Discussions: https://github.com/huyuhui001/MathKids/discussions

  • GitHub Issues: https://github.com/huyuhui001/MathKids/issues

✅ Summary | 总结

English: In summary, MathKid is a privacy-first application that:

  • ✅ Collects zero personal data
  • ✅ Requires zero permissions
  • ✅ Uses zero third-party services
  • ✅ Stores all data locally on your device
  • ✅ Functions completely offline
  • ✅ Is completely safe for children

中文： 总之，MathKid是一款隐私优先的应用程序：

  • ✅ 零个人数据收集
  • ✅ 零权限要求
  • ✅ 零第三方服务
